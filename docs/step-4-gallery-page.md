# Step 4 — Gallery Page

## Objective
Build the main gallery page with a responsive photo grid, hover effects, and a custom fullscreen lightbox viewer.

## Sections

### 1. Page Header
- **Title**: "Gallery" — large, centered heading with spacing below
- **Optional filter bar**: Category buttons (All, Landscape, Portrait, Street, etc.)
  - Clicking a category filters the grid to show only matching photos
  - "All" is active by default
  - Uses `data-category` attributes on gallery items

### 2. Photo Grid (Dynamically Loaded from Cloudinary)
- **Layout**: CSS Grid
  - Desktop: 3 columns
  - Tablet (< 1024px): 2 columns
  - Mobile (< 768px): 1 column
- **Gap**: ~15px between items
- **Images**: Fetched dynamically from Cloudinary `gallery` tag/folder via `cloudinary.js`
- **Each grid item** (generated by JS):
  ```html
  <div class="gallery-item" data-category="landscape">
    <img src="https://res.cloudinary.com/drijkt0we/image/upload/c_fill,w_600,q_auto,f_auto/gallery/photo-name"
         alt="Photo description" loading="lazy">
    <div class="gallery-overlay">
      <span class="gallery-title">Photo Title</span>
    </div>
  </div>
  ```
- **Cloudinary transformations used**:
  - Thumbnails: `c_fill,w_600,q_auto,f_auto` (auto WebP, 600px wide)
  - Lightbox full-size: `c_limit,w_1920,q_auto,f_auto` (max 1920px wide)
- **Hover effect**: Dark overlay fades in with the photo title centered
- **Loading state**: Skeleton grid placeholders while fetching from Cloudinary
- **Auto-update**: Upload a photo to the `gallery` folder in Cloudinary → it appears on the site automatically

### 3. Lightbox

A custom fullscreen overlay triggered when clicking any gallery image.

#### Features
- **Overlay**: Full-screen dark background (`rgba(0,0,0,0.95)`)
- **Image**: Centered, max-width/max-height constrained to viewport
- **Controls**:
  - Close button (X) — top right
  - Previous arrow (←) — left side
  - Next arrow (→) — right side
- **Keyboard support**:
  - `Escape` → close lightbox
  - `ArrowLeft` → previous image
  - `ArrowRight` → next image
- **Click outside image** → close lightbox
- **Transition**: Fade-in animation when opening

#### HTML Structure
```html
<div class="lightbox" id="lightbox">
  <button class="lightbox-close">&times;</button>
  <button class="lightbox-prev">&#10094;</button>
  <button class="lightbox-next">&#10095;</button>
  <img class="lightbox-img" src="" alt="">
</div>
```

## Completion Criteria
- Grid displays 12–16 photos responsively across breakpoints
- Hover overlay shows photo title
- Clicking a photo opens the lightbox with that image
- Lightbox prev/next navigates through all gallery images
- Keyboard controls (Esc, ←, →) work correctly
- Body scroll is locked when lightbox is open
- Category filter buttons work (if implemented)
- All images use `loading="lazy"` for performance
